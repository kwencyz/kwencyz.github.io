# Haziq Ruslan Photography

Portfolio site for convocation, portrait and candid photography in Shah Alam, Selangor.
Plain HTML, no build step. Hosted on GitHub Pages.

## Update contact details
In `index.html`, search for `const CONTACT` and fill in WhatsApp (with country code, e.g. `60123456789`), Instagram handle and email.

## Gallery links
Add one of these to the end of the site address to open a gallery directly:
`#convocation` `#portraits` `#events` `#friends` `#candids` `#golden-hour` `#outdoors`
